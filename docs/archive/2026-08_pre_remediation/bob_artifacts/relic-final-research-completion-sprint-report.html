F. Remaining Scientific Limitations

  • Single dataset: CardDemo only. One demonstration application.
  • Simulation circularity (RQ3): EXECUTION_SIMULATED traces from same JCL parser as BCG; promotion near-guaranteed structurally.
  • Oracle spec-sharing (RQ1): Oracle and SUT share deterministic JCL spec; F1=1.0 is expected for any correct implementation.
  • No held-out split (RQ1): Split key mismatch → fallback to full directory; evaluates on development files.
  • OOD unevaluable: public_cobol has no oracle; F1=0.0 is benchmark incompatibility, not extractor failure.
  • LLM baselines confounded: 97–99% API failure rate makes comparison inconclusive beyond "RELIC > LLM lower bound."
  • GnuCOBOL ≠ z/OS: Real execution from non-mainframe environment only.
  • TEMPORAL-only independent validation: RESOURCE/CONTROL_FLOW require human annotation (blocked).
