# Ground Truth Independence Report
## LEGACY-CONTRACT — RQ1 Validity Assessment

**Date:** 2025  
**Status:** RQ1 = BLOCKED_FOR_INDEPENDENT_VALIDATION

---

## 1. The Problem

The Level-2 DETERMINISTIC ground truth was generated by the BCG static extractor —
the same algorithm under evaluation. This creates a circular dependency:

```
Extractor → Ground Truth → Evaluate Extractor → F1 = 1.00 (guaranteed)
```

F1 = 1.00 is the mathematically expected outcome when the evaluator and the evaluated
system are the same function applied to the same input. It is an idempotency confirmation,
not a measure of correctness.

**This is not a failure of experimental design.** Level-2 ground truth is a legitimate
and necessary milestone for confirming that the extractor is deterministic and stable.
The failure would be claiming that F1 = 1.00 demonstrates real-world accuracy.

---

**RQ1 status: BLOCKED_FOR_INDEPENDENT_VALIDATION**

The hypothesis H1 (F1 ≥ 0.70, Precision ≥ 0.75) is trivially satisfied within the
Level-2 self-consistency evaluation. It must not be presented as evidence of
independent accuracy.

---

## 3. What the Level-2 Result Proves

- The extractor is **deterministic**: identical output across multiple runs on the same input.
- The extractor is **internally consistent**: it extracts exactly the contracts it was
  designed to extract, from the artifacts it was trained on.
- The **static evidence pipeline** is stable and reproducible.
- The result is a **valid engineering check** that the system has not regressed.

## 4. What the Level-2 Result Does Not Prove

- That extracted contracts **correspond to semantic obligations** in the source JCL.
- That the extractor would achieve F1 ≥ 0.70 against **independent human judgment**.
- That the extractor has **acceptable precision on obligation-free JCL** (FPR is undefined).
- That results **generalize beyond CardDemo**.
- That the **RESOURCE contract type** performs reliably (n=3 is insufficient).

---

## 5. Level-3 Annotation: What Is Required

To obtain a non-circular evaluation:

1. **Independent annotators** (domain experts who have not seen extractor output) must
   label JCL artifacts for behavioral contracts without any system guidance.

2. The annotation package must be prepared using `scripts/export_blinded_annotation.py`,
   which strips all system-generated fields before export.

3. **Inter-annotator agreement** (Cohen's κ ≥ 0.60) must be confirmed before using
   the annotations as ground truth.

4. The evaluation pipeline (`evaluation/benchmark.py`) must be re-run with
   `level3_human.json` as the ground truth source.

5. Results from the Level-3 evaluation **replace** (not supplement) the Level-2
   self-consistency result for any claim about "precision and recall."

---

## 6. Until Level-3 Is Complete

All RQ1 claims must be stated as:

> "The available Level-2 benchmark evaluates extraction **self-consistency** rather
> than independent recovery accuracy. The extractor achieves F1 = 1.00 within this
> self-consistency evaluation, confirming deterministic and reproducible extraction.
> Independent precision/recall measurement requires Level-3 human annotation,
> which has not yet been conducted."

RQ1 is marked: **BLOCKED_FOR_INDEPENDENT_VALIDATION**

---

## 7. Impact on Other Sections

This independence gap does not invalidate RQ2 or RQ3. The RQ2 mutation benchmark
evaluates risk *detection* (not contract *recovery*): given extracted contracts, does
the system detect when they are violated? This is independent of whether the contracts
correspond to true semantic obligations. The mutation benchmark's ground truth is
determined by whether a mutation was applied — not by whether the original contract
was semantically correct.

RQ3 (dynamic validation rate) is also independent: it measures whether execution
traces confirm or contradict statically extracted contracts. This is meaningful
regardless of whether the contracts reflect true obligations.

Only RQ1 (contract recovery against independent ground truth) is blocked.
