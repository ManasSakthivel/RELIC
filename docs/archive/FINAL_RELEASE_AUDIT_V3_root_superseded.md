## 19. Novelty Assessment

**Defensible claim:** To our knowledge, LEGACY-CONTRACT is the first system to formalize implicit behavioral obligations across both JCL and COBOL artifacts simultaneously, with per-contract provenance, an explicit static/dynamic reconciliation taxonomy, and a fault-grounded mutation evaluation framework derived from documented real-world modernization failures.

**Not claimed:** Behavioral contracts (Meyer 1992), dynamic invariant inference (Daikon), trace mining (Ammons, Lo/GIST), semantic differencing (Pessoa, SYMDIFF), LLM analysis.

**Honest positioning:** Narrow novelty. The contribution is the combination and formalization, not any individual component. Prior work covers adjacent problems; no prior work covers this specific combination at the JCL+COBOL cross-artifact level.
