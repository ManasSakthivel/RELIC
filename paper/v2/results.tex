\subsection{Language-model comparison (not interpretable)}
Source: \texttt{results/final/raw/llm\_status.json} and \texttt{v2\_metrics.json},
\texttt{llm\_selection\_analysis}. Model: \texttt{openai/gpt-oss-20b} via the
nvidia provider, prompt \texttt{source\_diff\_v4}, temperature 0, one sample.
All 566 evaluable mutants were attempted; 183 have no valid output from at least
one baseline (C: 148 and D: 103 \texttt{INVALID\_OUTPUT}, ``no JSON object in
response''). The unscored are 89.6\% positive; the 383 scored are 77.3\% positive.
On the 383-mutant common subset (selection-biased, not a random subsample):
C F1 0.9846, D 0.9671, v1.0 0.9077, v1.1 0.9577, V2 0.9793, text change 0.9442.
Bounds over all 566 (invalid output as not flagged / as flagged):
C 0.8083 / 0.9717; D 0.8468 / 0.9536. These records neither show RELIC beating
nor losing to the models. A fair comparison with a documented provider/model,
an invalid-output retry policy and full coverage is
\textbf{[PENDING EXPERIMENT]}.
