## Key Files

### `FINAL_RESULTS_MANIFEST.json` (authoritative)

Version 1.4, `frozen=true`. All paper numbers trace to this file.
Do not edit this file — it is the frozen record of all final experimental results.

### `rq1/rq1_independent.json` (authoritative for RQ1)

Independent oracle evaluation. Oracle is a separate regex-based implementation
that shares the JCL specification but no code with the main extractor.
Scope: TEMPORAL contracts only (33 held-out JCL files).

**Do not use `rq1_summary.json`** — it is a deprecated self-consistency check,
not an independent evaluation.

### `rq2/rq2_summary.json` (authoritative for static baselines)

Contains final results for BCG (proposed), Baseline A (structural), Baseline B
(complexity), and Baseline E (static BCG without confidence-delta).

LLM baseline results are in separate files:
- `rq2/llm_c_results.json` — Baseline C (LLM-only)
- `rq2/llm_d_results.json` — Baseline D (Dep+LLM)

LLM run configuration: Groq `llama-3.3-70b-versatile`, temperature=0, v2_blinded
prompts, seed=42. v1 prompts were discarded (semantic leakage). See `llm_config.json`.

### `rq3/rq3_dynamic_results.json` (authoritative for RQ3)

Final dynamic reconciliation results: 56/61 SUPPORTED (91.8%), 1 CONFLICT, 4 NOT_OBSERVED.
Traces: 40 total (2 real GnuCOBOL EXECUTION + 38 EXECUTION_SIMULATED JCL ordering).
**NOT z/OS execution.**
